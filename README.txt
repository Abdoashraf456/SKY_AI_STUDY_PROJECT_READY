SKY AI STUDY - Flutter project files

IMPORTANT: Upload/extract these files into the ROOT of your GitHub repository, keeping this exact structure:

pubspec.yaml
lib/main.dart
.github/workflows/build-apk.yml

Then open GitHub > Actions > Build SKY AI STUDY APK > Run workflow.
After it finishes, open the completed run and download the artifact named SKY-AI-STUDY-APK.

If using an IDE instead of GitHub Actions, create lib/main.dart and paste the supplied Dart code there; pubspec.yaml belongs in the project root (next to the lib folder).
